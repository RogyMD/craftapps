# CraftApps library submission

The library (CraftApps Library) collects apps people made with CraftApps, so others with the same problem can use and improve them instead of building them again.

Submissions are emails **the person sends from their own email account** to:

**craft.apps@aigarden.uk**

Only for apps shared **publicly** with a license. The maintainer reviews every submission before anything is listed.

## Draft for the person

Fill in from the approved share. Use a **link** to where the project is shared (any code host, Dropbox, Google Drive, …) — not an attachment. Leave the sender blank; never guess their address.

```
To: craft.apps@aigarden.uk
Subject: CraftApps library submission: <app name>

App name: <name>
What it solves: <one or two sentences, in their words, with no private details>
Platforms: <e.g. iPhone, Mac>
Where to get it: <public link>
License: <e.g. MIT>
Status: <e.g. "works on my iPhone; not tested elsewhere">
Built with: CraftApps (build-app)
```

Before handing it over, check the text the same way as the shared files: no names of other people, addresses, or private details.

Tell the person: "Copy this into a new email and send it from your own address. The maintainer will review it and reply."

# Notes

## Release checklist (every release, ~every 6–8 weeks)

1. Bump version and build number
2. Copy commits since last tag → ask ChatGPT/Claude for What's New text
3. Ask for translations (de, fr, es, ja, ro)
4. Paste What's New into App Store Connect for each of the 5 locales + English
5. Check Localizable.xcstrings for missing translations (manual, I often forget)
6. Archive, upload, submit for review

## Monday routine

- Open Xcode Organizer → copy crashes + sessions for Pocket Plant Log, Tide Timer, Focus Jar into the "Crash tracking" Numbers sheet
- Takes ~20 minutes, boring, sometimes I skip it and then the chart has gaps

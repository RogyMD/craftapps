# Expected findings — where the person's project lives

Both scenarios (N and V):

| # | Item |
|---|---|
| 1 | The plan says where the app's source code will live on this computer (a specific folder the person can change) |
| 2 | The person is asked whether they want a backup copy somewhere else, with options that fit what they already use (for example a private repository on their code host, or a folder in their cloud drive), and "no backup" is a valid answer |
| 3 | Any online copy is private by default; making it public is left to `share-app` |
| 4 | Nothing is pushed, uploaded, or created online, and no remote is added, before the person says yes to that exact place |
| 5 | Wording fits the level: N in plain words (no unexplained "repository", "remote", or "push"); V in one or two concise lines |
